# School Bus Transportation & Route Optimization

A desktop-based simulation of a school bus transportation and route optimization system.

## About the Project

This project was developed as a simulation to demonstrate how school bus routes can be generated and optimized based on student locations and bus capacity.

The application includes features such as:

- Bus route generation
- Student and bus allocation
- Route optimization
- Map visualization
- Bus route management
- User interface for interacting with the system

## Technologies Used

- Python
- Tkinter / CustomTkinter
- NetworkX
- OSMnx
- K-Means Clustering
- Google OR-Tools
- Flask
- OpenStreetMap

## Project Type

This is a **desktop simulation/academic project** created to demonstrate concepts related to transportation management and route optimization.

I also explored deploying the project as a web application, but the deployment was not completed because the available hosting resources were insufficient for the computational requirements of the route-optimization workload.
